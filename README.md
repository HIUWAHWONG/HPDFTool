A clean and simple Python-based PDF utility featuring a visual interface for viewing, managing, and editing PDF files.

## Features
- **PDF Viewer & Editor**: Interactive viewing with support for on-page text extraction and in-place modifications.
- **Pure & Ad-Free**: Designed for maximum productivity without any distracting advertisements or pop-ups.
- **Stand-alone Application**: Can be compiled into a single executable for quick deployment.

## Prerequisites
- Python 3.x
- `pypdf` (for PDF core operations)
- `PyInstaller` (optional, for packaging)

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone <Your-GitHub-Repository-URL>
   cd HPDFTool
   ```
2. Install dependencies:
   ```bash
   pip install pypdf
   ```
3. Run the application:
   ```bash
   python HPDFTool.py
   ```
